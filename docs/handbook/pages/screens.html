Read the performance screen

  • Track strip, left. When stopped, A means armed, R recording, O overdubbing and P playing. S means the track is stopped on a recorded slot. A dash means the slot is empty. M means muted, including tracks silenced by another track’s solo. The selected track still shows its recording or playback state. When the transport runs, each strip shows MIDI note activity.
  • Piano roll, upper right. Read from left to right to follow the notes in your loop. Higher notes appear higher on the roll. Each note extends from its onset to its release. The playhead marks the current playback position. For loops longer than 16 bars, the piano roll shows one 16-bar page at a time.
  • Status, bottom. Read the four position numbers as bar, beat, sixteenth note and tick. TRACK and SLOT tell you which loop you are viewing. The output channel appears beside them. UNDO shows how many changes you can undo on that slot. During an overdub or note edit, ODUB or EDIT shows the undo count for that session.
  • Loop progress. Brackets mark the section of the loop that repeats. When a new slot is queued, a flashing playhead shows where it will start and a countdown shows how long until it plays.

Recognize a completed save

Look for the four dots above the tempo. Four dim dots mean a save is waiting. One moving bright dot means the looper is writing to the card. All four flash bright when the save finishes. A dimmer flash can indicate a failed save. If you see RO, check that the card was inserted before power-up and that saving is enabled.

Read the editing displays

In NOTE_EDIT, read the selected note’s start position, pitch, velocity and duration under START, NOTE, VELOCITY and LENGTH. The dotted bracket marks the edit position. LOOP_EDIT shows the loop start, length and tempo. Octave names vary between MIDI instruments. Use the MIDI note number when comparing a displayed pitch with your keyboard or DAW.

Use the hints on a window

Read the bottom row before pressing a key. [TRK] means Next Track, [EDT] means Edit, [PLY] means Play and [ADD] means NOTELEN. 2* marks a double press. In the GROOVE window the highlighted OFF, A or B shows which timing you hear; changing the other column prepares its next audition.
