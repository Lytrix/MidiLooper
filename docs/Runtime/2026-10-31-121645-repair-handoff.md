## 4. FIRST TASK — the tree currently has two deliberate REDs

An independent scoped review returned **REQUEST CHANGES** with one blocker, and the
two fixtures that pin it are in the tree failing on purpose. **Do not flash, commit
or mark 5.1 complete until they are green.**

**Blocker: equal inclusive endpoints are treated as a whole-loop note.**
`NoteUtils::reconstructDisplayNotes` closes a boundary pair (On at `loopLength - 1`,
Off at `0`) into a tail-only row `[loopLength - 1, loopLength - 1]`. Both helpers then
treat `end == start` as a wrap:

- `src/Utils/DisplayWindowUtils.cpp` — `displayNoteSpanInLoop`: `if (noteEndInclusive <= noteStart) exclusiveEnd += loopLength;`
  For `start == end` this yields a span of `loopLength + 1` — a whole-loop note, so the
  row is retained in every window. The same branch makes a one-tick note at tick 0 a
  whole-loop span.
- `src/Utils/DisplayWindowUtils.cpp` — `noteIntersectsWindow(uint32_t startTick, uint32_t endTick, ...)`:
  `if (noteEnd <= noteStart) noteEnd += loopLength;` — same equality error.

Required: distinguish **equal** (one tick) from **less-than** (genuine wrap). A note
whose end is before its start must still wrap; a note whose end equals its start must
be one tick at that position. Keep complete geometry — exclude a row or keep it, never
clip or re-pair its endpoints. Then verify both directions, not just the new case:
`test_display_window_utils` (including its existing in-place parity and sliding-prefix
callers) and `test_live_capture_display_boundary`, then `test_pending_note_change`,
`test_immediate_visual_cache_probe`, `test_immediate_capture_handoff`,
`test_frozen_record_reader_survival`, and finally full native + target build.

keep working (DEC-034 — overlap shorten seals at the user-triggered commit).

(`src/DisplayManager/DisplayNoteResolveLiveCapture.cpp` ~182–239, `tailEnd = loopLength - 1`),
which DEC-232 — circular display coverage already tried freezing once and **withdrew**
because it produced exactly this symptom. Do not re-freeze it without a new measurement.

Oracle requirements: a pending raw-only predecessor retirement while its successor is
live; capture exact NoteId + span before/after **each** service grain without draining
the finalizer between observations; assert untouched later notes are bit-identical;
separate viewport-stationary frames from one-bar moves and the wrap; include a control
