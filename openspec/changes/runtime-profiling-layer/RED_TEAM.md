# Red team — runtime profiling layer (revision of 2026-10-31)

Adversarial review of the rebased proposal/design/spec/tasks against HEAD `5ddba83e`. Each finding has
a failure scenario, a severity, and the disposition applied in this change. "Applied" means the
design/spec/tasks were edited in the same commit; "Deferred" means it is carried by
[RETIREMENT.md](RETIREMENT.md) or a later change.

| # | Sev | Finding | Failure scenario | Disposition |
|---|---|---|---|---|
| R1 | High | **A second timing table already exists and the change never names it.** `Diagnostics::Timing` (`include/Utils/Diagnostics.h`) keeps sum/count/max for 10 identities via `DIAG_TIMING_RECORD` at 15 call sites (display build/compose/sync/replace/tails, `DisplayUpdateTotal`, `PlaybackBuild`), compiled into **every** `SESSION_CAPTURE` image and emitted as `DIAG,timing` / `DIAG,timing_max`. D1 only reasons about `HotPathTelemetry`. | `Display_frame_phase`, `DisplayBase_gather` and `PlaybackWindow_build` would be timed three ways (profiler, `Diagnostics::Timing`, `HotPathTelemetry` for display update), with three rounding rules and a reviewer unable to say which number is authoritative. | **Applied:** D1 names both facilities, records that neither is migrated here, and assigns the profiler as the intended successor. Retirement path in RETIREMENT.md stage 2. |
| R2 | High | **Retirement is impossible while the profiler is profile-env-only.** The acceptance images (`teensy41-capture-serial`, `-no-grain`) are where the existing rows are read. | A row is retired because the profiler "covers" it; the next acceptance capture on the default image has no timing for that owner at all. | **Applied:** TBD-4 added (profiler promotion into the default capture env after the slice-4 A/B). RETIREMENT.md makes promotion a precondition of any default-image removal. |
| R3 | High | **`view_prewarm_step` is a synchronization signal, not only a timing row.** `scripts/hitl_midifile_chain.py` and `scripts/hitl_view_prewarm_active.py` wait for `view_prewarm_step,...,ready=1` before pressing Record (DEC-231). | Retiring the row with its timing breaks both rigs: the chain presses Record before preparation and reproduces the pre-DEC-231 pending edge. | **Applied:** TBD-2 narrowed to the `us=` field only; the readiness event stays. RETIREMENT.md class B. |
| R4 | Medium | **`capture_prewarm_split` carries a seven-way split the profiler does not reproduce.** The plan has one `PlaybackPrewarm_views` child; stopjobs/canonical/horizon/companion/order live only in the row. | The row is retired after "equivalence" on `views` alone and the next prewarm regression in `canonical` or `horizon` is invisible again. | **Applied:** retirement requires either child identities for every reported reserve or keeping the row (RETIREMENT.md class A precondition). |
| R5 | Medium | **Existing serial rows inside measured bodies inflate breaches.** `capture_prewarm_split` is emitted inside `prewarmPlaybackForSlot`; on a full USB TX buffer the direct write can wait. | `RecordStart_edge` breaches COLD because of the diagnostic row, and the ring attributes the stall to the Record edge. | **Applied (already in D11)**, plus the slice-3 oracle records the split row's own emission cost as part of `PlaybackPrewarm_slot` self time; profile env compiles nothing new inside the body. |
| R6 | Medium | **"Main-loop only" is a review claim with no runtime check.** | A future caller reaches an instrumented owner from an `IntervalTimer` callback; the depth stack is shared with the interrupted main-lane scope and is silently corrupted (no order fault, because the ISR scope exits LIFO). | **Applied:** scope entry reads `IPSR`; non-zero → measurement refused, `isrRefused` counted and reported in the stats terminator; native fixture via a fake IPSR shim. |
| R7 | Medium | **Double probe cost in the A/B.** Display update carries `HotPathTelemetry` + `Diagnostics::Timing` + the new scope; overdub start carries `HotPathTelemetry` + the new scope. | The slice-4 A/B attributes the existing timers' cost to the profiler, or a site is removed for overhead it did not add. | **Applied:** slice-4 A/B records the existing timers present in each site; removal decisions cite the profiler's own calibration, not the site's whole delta. |
| R8 | Medium | **Depth-zero gate assumes command dispatch is outside every scope.** `SaveWorkItem_step` and `LoadStep` run in the storage lane; HITL serial dispatch lives in `StorageManagerHitlSerial.cpp`. | If dispatch is reached from inside a storage step, every profile command is refused forever during a save. | **Applied:** task 1.1 verifies the dispatch call chain is outside all thirteen scopes. |
| R9 | Low | **`Diagnostics::Timing` sums are `uint32_t` µs.** | After 71.6 min of cumulative display time the `DIAG,timing` average is wrong; a profiler/legacy comparison in a long soak "disagrees". | **Deferred:** noted in RETIREMENT.md as a reason the legacy table is not the equivalence reference for long runs. |
| R10 | Low | **Every profile prefix needs a marker pre-flight, not only `profile_stat`.** | `profile_cmd,refused` is not Tier-A and is shed under transport; the host retries forever without seeing the refusal. | **Applied:** task 3.3 runs `check_marker_contract.py` for all five prefixes. |
| R11 | Low | **Equivalence band for `ViewPrewarm_unit` hides overhead.** ±50 µs is generous against a ~0.15 µs scope. | A placement error (scope around the row) still passes. | **Applied:** band tightened to ±10 µs plus a check that the profiler value is ≤ the row's value (the row brackets a superset). |
| R12 | Low | **Calibration identity could be dumped.** | Host decoder shows a phantom identity with 256 calls. | Already covered (cleared after calibration); decoder skips the reserved id. |

## Not findings (checked and rejected)

- **Wrap of the ring timestamp after 71.6 min** — `seq` carries ordering; `t_us` is informational.
- **`micros()` called from early `setup()`** — systick and DWT are running before `setup()`.
- **Native `DMAMEM` zero-init hiding the boot clear** — already addressed by the pre-filled fixture (D13).
