- [x] 3.3 Implement the rejected-submission and timeout recovery paths: recover the wrapper before blocking SPI on timeout, send a full resynchronization frame, retry after the configured delay, and enter boot-local SPI degraded mode after the limit; verify diagnostics distinguish each state and a transient injected failure returns to DMA. **Done (2026-09-24):** with the injected faults — forced timeout (`MIDILOOPER_DISPLAY_DMA_FAULT=2`, `COUNT=2`) gives `timeouts=1→2` then `DMA recovered`, `recoveries=1`, `degraded=0`, with one blocking-SPI frame during the cooldown; forced rejection (`=1`, `COUNT=2`) gives `rejections=2` then the same recovery; the permanent variants reach `DMA degraded for this boot` at the third consecutive failure and then serve every frame over blocking SPI.
