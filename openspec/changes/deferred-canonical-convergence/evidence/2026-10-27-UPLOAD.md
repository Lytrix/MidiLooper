1. A **window-only** canonical denial is no longer treated as base abandonment: the companion/note-edit path

3. No phase-wide supersession gate; the deferred obligation is recorded **after** the raw commit.
4. `reset()` no longer cancels the obligation (a playback reset is not a slot replacement); a restarted
   committed timeline does.

- A window denial now names itself: `Deferred stop stalled: canonical bridge window denied; companion path kept`.
